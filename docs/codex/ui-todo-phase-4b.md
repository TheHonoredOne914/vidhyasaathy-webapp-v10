# Phase 4 backend integration

- Ask: `POST /ask/stream` emits named SSE events; display the guarded `done.text`. Unconfigured AI uses the grounded notes-only provider, not a fabricated conversation. `/ask/status` reports actual text/photo capability and budget. Photo failures return friendly status, never credentials.
- Quick try: `quickTry` contains `itemId`, `stem`, public `{id,text}` options. Submit `POST /ask/quick-try/:itemId/answer` with `{threadId,clientEventId,optionId}` (optional confidence); the earlier static endpoint remains an alias. Preserve the event ID for retries. Response contains `correct`, `correctOptionId`, `explanation`, `evidenceSaved`, `xp`; keys only arrive after marking. Wrong answers schedule a real follow-up.
- Threads/saved: `/ask/threads`, `/ask/threads/:id`, `/ask/saved`; owner-only. Raw messages expire after 24 hours, saved explanations and opted-in teacher replies remain. Escalation is explicitly opt-in via `/ask/escalate`; no unmocked confirmation UI added.
- Games: `/student/games` adds subjects, counts, today's game and real published chapter game cards, retaining legacy `chapters`/`atomForge`. Atom is available under the approved atom-kz flow, not the stale paused design. It has no scored session endpoint.
- Nine scored games: `/games/:id/sessions` starts an owned session with frozen public checkpoints. Submit `/games/:id/sessions/:sessionId/answer` with the offered checkpoint key/option ID, confidence and time. Finish only after every checkpoint has been marked. Start/answer/finish require stable client event IDs; mismatched replay is 409. `/games/:id/best` and finish return historical best and canonical earned XP, never invented physics metrics.
- Game/Ask evidence has weight 0.5; it cannot alone establish/promote mastery or advance the concept ladder. Existing interactive arenas must be retained; replace only checkpoint content/marking with these server items.
- Ask evidence uses `source='practice', source_detail='ask'` to preserve the existing SQLite source CHECK without rebuilding or deleting evidence. Thread events/details return the actual concept, chapter and subject for the Talking about rail.
- Empty/missing published content stays unavailable; never substitute mock questions, fake scores or cross-topic mappings. The additive demo bank has four NCERT checkpoints per existing game, scoped to the demo school.
