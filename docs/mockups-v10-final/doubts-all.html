Why is displacement zero if I ran a full 400 m round the track?
Motion · Distance & displacement · Tue 7:05 pm · asked Ma'am
Ma'am replied Saved
Saathy's explanation · savedkept until you remove it
Displacement only cares about where you start and where you end. One full lap brings you back to the start line, so the straight-line gap is 0 m. Distance still counts every step: 400 m.
